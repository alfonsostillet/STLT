STLT 1.0.1: fixes from the first reports, and a choice for the layer's speed fader.

🇮🇹 **STLT 1.0.1**. Correzioni dalle prime segnalazioni e una nuova preferenza. Scarica il file per il tuo sistema qui sotto, in *Assets*; si installa come la 1.0 e le impostazioni restano quelle che hai.

- **Windows** (`STLT-v1.0.1-windows.zip`): estrai tutta la cartella (tasto destro → *Estrai tutto*) e avvia `STLT.exe`. Il programma non è firmato: se Windows mostra "Windows ha protetto il PC", clicca *Ulteriori informazioni* → *Esegui comunque*.
- **macOS** (`STLT-v1.0.1-macos.zip`, Apple Silicon): estrai e sposta `STLT.app` dove vuoi. L'app non è firmata da Apple: la prima volta aprila col tasto destro → *Apri* (oppure *Impostazioni di Sistema → Privacy e sicurezza → Apri comunque*).
- **Linux** (`STLT-v1.0.1-linux.tar.gz`): compilato su Ubuntu 24.04, usa le librerie FFmpeg, GLEW e GTK 3 del sistema; avvia `stlt`.

## Novità rispetto alla 1.0.0

- **Il fader S nell'intestazione del layer, a scelta**: in *Preferences → General → Speed fader (S) in a layer's header* scegli se muove la velocità del layer (si moltiplica con quella della clip, come finora) o la velocità della clip in onda, che ogni clip tiene per sé. Anche il MIDI e l'OSC del fader seguono la scelta. ([#2](https://github.com/alfonsostillet/STLT/issues/2))
- **Menu Clip senza errori**: senza una clip selezionata, passare sulle voci del menu *Clip* mostrava messaggi di errore di Dear ImGui. ([#1](https://github.com/alfonsostillet/STLT/issues/1))
- **Campi numerici**: la dimensione personalizzata della composizione, la dimensione di uno schermo nell'Advanced Output e la porta OSC si applicano quando hai finito di scrivere (Invio, Tab o un clic altrove), senza l'opzione che le versioni nuove di Dear ImGui non accettano più.

Grazie a [@vjgrobkorn](https://github.com/vjgrobkorn) per le segnalazioni.

## English

STLT 1.0.1 fixes the first reports and adds one preference. *Preferences → General → Speed fader (S) in a layer's header* chooses whether that fader (and its MIDI and OSC) sets the layer's speed, which multiplies the clip's own as before, or the speed of the clip playing on the layer, which each clip keeps ([#2](https://github.com/alfonsostillet/STLT/issues/2)). Hovering the *Clip* menu with no clip selected no longer shows Dear ImGui errors ([#1](https://github.com/alfonsostillet/STLT/issues/1)). The composition's custom size, a screen's size in the Advanced Output and the OSC port apply once you finish typing. Thanks to [@vjgrobkorn](https://github.com/vjgrobkorn) for the reports. The programs are not signed: on Windows choose *More info → Run anyway*, on macOS right-click → *Open* the first time. See [app/README.md](https://github.com/alfonsostillet/STLT/blob/main/app/README.md).
