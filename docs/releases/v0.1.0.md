The first release of STLT-VJ.

🇮🇹 **Prima release di STLT-VJ.** Scarica il file per il tuo sistema qui sotto, in *Assets*.

- **Windows** (`STLT-VJ-v0.1.0-windows.zip`): estrai la cartella e avvia `stlt-vj.exe`. Il programma non è firmato: se Windows mostra "Windows ha protetto il PC", clicca *Ulteriori informazioni* → *Esegui comunque*.
- **macOS**: arriverà con una prossima versione.
- **Linux** (`STLT-VJ-v0.1.0-linux.tar.gz`): compilato su Ubuntu 24.04, usa le librerie FFmpeg e GTK 3 del sistema.

## What's in it

- **Clip deck**: layers, columns and decks; launch modes, transitions, cue points, in/out points, beat-synced animations and effects, FFGL plugins.
- **Arrangement view**: a timeline with tracks, audio, keyframes with curves, and cue blocks with end actions.
- **Output**: Off, Window, Fullscreen, or the **Advanced Output** (slices, polygons, warps, contours, masks, soft edges, Spout/Syphon/NDI, import from Resolume).
- **Chaser**, built in: *Output → Chaser...* lights the slices step by step, to the beat.
- **Control**: keyboard, MIDI and OSC mapping with presets; Preferences; Clip menu with copy, paste and resize.

The full guide is in [app/README.md](https://github.com/alfonsostillet/STLT/blob/main/app/README.md).
